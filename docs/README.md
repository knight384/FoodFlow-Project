## Planning documents (approved baseline)

All seven approved planning documents are in `planning/`, in the order they
were produced and approved:

1. `Project_Foundation_Scope_Definition_v1.1.md`
2. `Product_Requirements_Document_PRD_v1.0.md`
3. `Software_Requirements_Specification_SRS_v1.0.md`
4. `Technical_Requirements_Design_Document_TRD_v1.0.md`
5. `Database_Specification_v1.0.md`
6. `API_Specification_v1.0.md`
7. `ML_and_Testing_Plan_v1.0.md`

These are the authoritative source of truth for all implementation work.
Later implementation phases should not contradict them; where a decision
is explicitly left open in these documents, implementation should track
it rather than resolve it silently (see each document's "Deferred
Decisions" / "Open Questions" sections).
